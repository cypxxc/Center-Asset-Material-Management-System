# ชุดเตรียมนำเข้าวัสดุ ปีงบประมาณ 2570

ข้อมูลจากไฟล์ต้นฉบับ 4 ไฟล์: 76 รายการ ยอดศูนย์ 42 รายการ มูลค่าตามไฟล์รวม 38,776 บาท เป็นยอด ณ 31 ต.ค. 2569

คงข้อมูลต้นฉบับตามคำสั่ง: ไม่แปลงหน่วย ไม่เปลี่ยนชื่อ ไม่รวมชื่อกับขนาด ไม่แก้ราคา/จำนวน และไม่เติมค่าว่าง ตรวจ SHA-256 แล้วไฟล์ต้นฉบับไม่เปลี่ยนแปลง ขนาด รหัสวัสดุ ขั้นต่ำ สูงสุด และที่มาของแต่ละแถวเก็บแยกใน manifest และข้อมูลอ้างอิงของรายการ ไม่ใช้รหัสวัสดุเป็นเลขครุภัณฑ์

## ไฟล์ใช้งาน

- materials-2570-snapshot.csv: สำหรับเมนูตั้งค่า > นำเข้าพัสดุ CSV/Excel (`/settings?tab=import`)
- ตรวจสอบวัสดุ-2570.xlsx: สำหรับอ่านตรวจทาน ไม่ใช่ไฟล์สำหรับอัปโหลดเข้าตัวนำเข้าโดยตรง ข้อมูลกับข้อสังเกตอยู่คนละชีต
- materials-2570-manifest.json: ค่าต้นฉบับรายเซลล์ รหัสอ้างอิงแถว และ SHA-256

ยังไม่ได้นำเข้าฐานข้อมูลใช้งานจริง ข้อมูลนี้เป็นยอดตามวันที่ในไฟล์ ไม่ได้ปรับเป็นยอดปัจจุบัน และไม่ได้ย้ายประวัติรับ–จ่ายจากชีตรายตัวทั้งหมด การนำเข้าจริงต้องใช้บัญชีผู้ดูแลผ่านหน้าระบบ

## สิ่งที่แก้ในระบบ

- ตัวนำเข้าคงจำนวน 0 และปฏิเสธจำนวนผิดรูปแบบ แทนการเปลี่ยนเป็น 1
- ยอมรับวัสดุคงเหลือ 0 แต่ครุภัณฑ์ยังต้องมีจำนวนมากกว่า 0
- หน้าฟอร์มแสดงจำนวนและมูลค่าของวัสดุยอดศูนย์ถูกต้อง
- ป้องกันวัสดุซ้ำในไฟล์และกับรายการในระบบ รวมขนาด/ลักษณะที่เก็บแยกและรหัสแถวต้นฉบับในการตรวจซ้ำ

## ผลตรวจ

- เปรียบเทียบ 1,315 เซลล์ตรงกับ Excel ต้นฉบับ และตรวจไฟล์ทบทวนครบ 76 แถว
- การทดสอบเฉพาะส่วน 7 รายการผ่าน
- ทดสอบฟังก์ชันนำเข้าจริงบนฐานข้อมูลชั่วคราวผ่าน: 76 รายการ ยอดศูนย์ 42 รายการ มูลค่า 38,776 บาท นำเข้าซ้ำถูกปฏิเสธ ข้อผิดพลาดแถวท้ายไม่ทิ้งข้อมูลบางส่วน
- ใช้ restricted app connection และ RLS พร้อมตัวตน admin จำลองในฐานข้อมูลทดสอบ ไม่ใช่การทดสอบล็อกอินผ่านเบราว์เซอร์ ย้อน transaction และลบเฉพาะฐานข้อมูลทดสอบที่สร้างใหม่แล้ว
- TypeScript และ lint ผ่าน
- ชุดทดสอบรวมติดข้อผิดพลาดเดิม React is not defined ใน image-crop-dialog.test.tsx
- Build ติด EPERM ขณะลบ DLL ของ sharp ใน standalone ที่กำลังถูกใช้งาน ไม่ได้หยุดเซิร์ฟเวอร์ที่เปิดอยู่

สร้างชุดข้อมูลซ้ำ: `npx tsx scripts/prepare-materials-2570.ts`
ทดสอบแยกฐานข้อมูลชั่วคราว: `node --conditions=react-server --import tsx scripts/verify-material-import.ts`
## ฟอร์มนำเข้าในระบบ

ที่ ตั้งค่า > นำเข้าพัสดุ มี dropdown เลือก 2 ฟอร์มแยกกัน:

- นำเข้าครุภัณฑ์: CSV/Excel รูปแบบทะเบียนเดิม พร้อมดาวน์โหลดเทมเพลต
- นำเข้าวัสดุ: อัปโหลดไฟล์บัญชีวัสดุต้นฉบับปี 2570 ได้ครั้งละ 1–4 ไฟล์ แสดงสรุปจำนวน ยอดศูนย์ มูลค่า และวันที่ตามต้นฉบับ ก่อนกดยืนยันนำเข้าวัสดุ

การใช้งานใหม่ให้เลือกฟอร์มนำเข้าวัสดุและอัปโหลด Excel ต้นฉบับ ไม่ต้องนำไฟล์ตรวจทานไปอัปโหลด ฟอร์มครุภัณฑ์จะปฏิเสธข้อมูลชนิด material เพื่อป้องกันใช้ฟอร์มผิดประเภท

ตรวจ UI ด้วยเบราว์เซอร์จำลองการบันทึก: อ่านไฟล์จริงครบ 76 รายการ และตรวจหน้าจอ 1365px/390px ไม่ล้นแนวนอน เป็นการตรวจแยกจากเซสชันล็อกอินจริง ไม่ได้บันทึกฐานข้อมูลจริง

## เทมเพลตกลางร่วมกัน

ปรับตามคำขอเพิ่มเติมให้ทั้งสองฟอร์มดาวน์โหลด Excel ที่ใช้หัวคอลัมน์ชุดเดียวกัน โดยตัวอย่างระบุชนิด asset หรือ material ตามฟอร์มที่เลือก ฟอร์มวัสดุรองรับ CSV/Excel ตามเทมเพลตกลาง รวมถึง CSV ที่เตรียมไว้ก่อนหน้า และยังรองรับ Excel บัญชีวัสดุต้นฉบับทั้ง 4 หมวด

ตัวอ่านเทมเพลตกลางคงจำนวน 0 และข้อความที่มี comma/อัญประกาศ/ขึ้นบรรทัดใหม่ ไม่เติมจำนวนจากค่าว่างหรือเครื่องหมายขีด ไม่แสดงมูลค่าที่ขาดราคาเป็นศูนย์ และปฏิเสธคอลัมน์ที่ไม่รู้จักแทนการตัดทิ้ง ชุดตรวจเฉพาะส่วนล่าสุด 17 รายการผ่าน
