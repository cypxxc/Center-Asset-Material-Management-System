# การใช้งานเบิก / ยืมและบัญชีวัสดุ

## วัสดุ

- ส่งคำขอเบิกแล้วตัดยอดคงเหลือทันที การอนุมัติไม่ตัดซ้ำ
- ถอนคำขอหรือไม่อนุมัติจะคืนยอดครั้งเดียว ฉบับร่างยังไม่ตัดยอด
- แก้ชื่อ หมวดหมู่ หรือข้อมูลทะเบียนจากฟอร์มวัสดุได้ ส่วนจำนวนคงเหลือใช้ส่วน **รับเข้า / ปรับยอดตรวจนับ** ในหน้าแก้ไขวัสดุ พร้อมเหตุผลและเอกสารอ้างอิง
- ปรับยอดตรวจนับเทียบกับยอดล่าสุดที่โหลด หากมีการเคลื่อนไหวระหว่างตรวจนับ ต้องโหลดและตรวจนับใหม่
- รับคืนวัสดุใช้ไม่หมดจากรายการในหน้าเบิกจ่ายหรือรายละเอียดเอกสาร ระบุจำนวนส่งคืนและจำนวนตรวจรับพร้อมใช้แยกกัน เฉพาะจำนวนพร้อมใช้เพิ่มสต็อก จำนวนไม่พร้อมใช้เก็บในเอกสารรับคืนและเหตุผล
- รับคืนสะสมเกินที่จ่ายไม่ได้ เมื่อรับคืนแล้วจะย้อนเอกสารจ่ายทั้งฉบับไม่ได้
- บัญชีแสดงยอดตั้งต้นรวมการเคลื่อนไหวเทียบยอดปัจจุบัน หากไม่ตรงกันจะแจ้งผลต่างโดยไม่ปรับยอดให้อัตโนมัติ
- วัสดุที่มีเอกสารบัญชีแล้วเก็บประวัติไว้ การลบถาวรจะติดข้อจำกัดอ้างอิงเอกสาร ใช้การเก็บเข้าถังขยะหรือสถานะตามขั้นตอนเดิมแทน

## ครุภัณฑ์

เลือกเบิกหรือยืมต่อรายการได้ ยืมต้องมีวันกำหนดคืนไม่ก่อนวันปัจจุบันตามเวลากรุงเทพฯ คำขอที่ค้างจนพ้นกำหนดต้องระบุวันคืนใหม่อย่างชัดเจนก่อนอนุมัติ ผู้ดูแลรับคืนก่อนถึงกำหนดได้ พร้อมระบุสภาพตามเดิม

## ชุดคำขอและการส่งซ้ำ

ตะกร้ารวมวัสดุและครุภัณฑ์ได้ ระบบแยกเอกสารตามการทำรายการและรวมในชุดคำขอเดียว สร้างครบทั้งหมดหรือยกเลิกทั้งธุรกรรมเมื่อเกิดข้อผิดพลาด หลังสร้างแล้วจัดการแต่ละเอกสารแยกกัน

การลองส่งข้อมูลเดิมด้วยรหัสคำขอเดิมจะได้เอกสารเดิมและไม่ตัดสต็อกซ้ำ หากไม่ได้รับผลตอบกลับ ใช้ **ตรวจสอบคำขอที่ส่งล่าสุด** ก่อนส่งใหม่ แม้รายการจะหมดสต็อกและหายจากหน้ารายการแล้วก็ตรวจสอบได้ ข้อมูลการลองส่งล่าสุดเก็บในแท็บเบราว์เซอร์นั้น

## ติดตามคำขอ

แยกเวลาส่งคำขอ อนุมัติ และผู้รับได้รับของจริง การบันทึกได้รับของไม่ตัดสต็อกเพิ่ม ข้อมูลเก่าที่ไม่มีเวลาจริงจะแสดงว่ายังไม่มีข้อมูล

กำหนด `MATERIAL_APPROVAL_SLA_HOURS` เป็นจำนวนชั่วโมงบวกในสภาพแวดล้อมเซิร์ฟเวอร์เพื่อแสดงการเตือนคำขอวัสดุค้างอนุมัติ หากไม่กำหนดจะแสดงอายุคำขอโดยไม่มีเส้นตาย ระบบไม่ยกเลิกคำขอหรือคืนสต็อกเองตามเวลา และไม่ส่งอีเมลอัตโนมัติ
