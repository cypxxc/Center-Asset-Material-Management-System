# Asset Number Series Design

## Goal

ทำให้การใช้เลขครุภัณฑ์เข้าใจง่าย โดยแยกการตั้งค่าแม่แบบออกจากการเพิ่มรายการทะเบียน และให้แม่แบบหนึ่งรองรับหลายชุดเลขที่เลือกได้ว่าจะออกเลขอัตโนมัติหรือกรอกเอง

## Concepts

- **แม่แบบเลขครุภัณฑ์** กำหนดโครงสร้างของเลข เช่น `สขส7.7110-{series}-{running:4}-11/58`
- **ชุดเลข** คือค่าของ token เช่น `series=006` ซึ่งเป็นบริบทของลำดับเลขหนึ่งชุด
- **โหมดอัตโนมัติ** ระบบออกค่า `running` ถัดไปภายในชุดเลขที่เลือก
- **โหมดกรอกเอง** ระบบคงส่วน static ของแม่แบบไว้ และให้ผู้ใช้ระบุเลขครุภัณฑ์เอง

## Settings UI

หน้าตั้งค่า “เลขครุภัณฑ์” สำหรับผู้ดูแลมีสองระดับ:

1. รายการแม่แบบ: ชื่อและรูปแบบเลข
2. รายการชุดเลขภายในแม่แบบ: ค่า `series`, โหมดอัตโนมัติ/กรอกเอง, เลขเริ่มต้น, เลขล่าสุด และสถานะเปิดใช้งาน

กำหนดเลขเริ่มต้นได้เฉพาะชุดเลขที่ยังไม่เคยออกเลข ระบบไม่อนุญาตให้ตั้งเลขล่าสุดย้อนหลังหลังมีการออกเลขแล้ว เพื่อป้องกันเลขซ้ำ

## New Item Modal

ฟอร์มเพิ่มทะเบียนใหม่มีตัวเลือกสั้น ๆ:

1. กรอกเลขครุภัณฑ์เอง
2. ใช้แม่แบบ

เมื่อใช้แม่แบบ ผู้ใช้เลือกแม่แบบและชุดเลข ระบบแสดงส่วนคงที่ของเลขอย่างอ่านง่าย หากชุดเลขเป็นอัตโนมัติ จะแสดงเลขถัดไปแบบ preview และจองเลขจริงพร้อมสร้างรายการใน transaction เดียวกัน หากชุดเลขเป็นกรอกเอง ระบบจะแสดงช่องกรอกเลขแทน

## Data and Integrity

- ชุดเลขผูกกับแม่แบบและค่า token ที่กำหนดเป็น scope ของลำดับ
- การจองเลขและสร้างรายการใช้ transaction เดียว
- มี unique index สำหรับเลขครุภัณฑ์ที่ไม่เป็นค่าว่าง
- CSV import ยังคงระบุแหล่งที่มาว่า import และไม่เปลี่ยนเลขอัตโนมัติ

## Verification

- สร้างชุด `006` แบบอัตโนมัติจากเลขเริ่มต้น 0001 และตรวจเลขถัดไป
- สร้างชุดอื่นแบบกรอกเองและตรวจว่าไม่ออกเลขอัตโนมัติ
- ทดสอบการสร้างพร้อมกันเพื่อยืนยันว่าเลขไม่ซ้ำ
- ทดสอบ modal สำหรับกรอกเอง, ใช้ชุดอัตโนมัติ และใช้ชุดกรอกเอง
