# Asset Number Series Design

## Goal

ทำให้การใช้เลขครุภัณฑ์เข้าใจง่าย โดยแยกการตั้งค่าแม่แบบออกจากการเพิ่มรายการทะเบียน และไม่ใช้การออกเลขอัตโนมัติ

## Concepts

- **แม่แบบเลขครุภัณฑ์** กำหนดโครงสร้างของเลข เช่น `สขส7.7110-{series}-{running:4}-11/58`
- **Preview** คือเลขที่สร้างจากแม่แบบและค่าเริ่มต้น ซึ่งผู้ใช้แก้ไขได้โดยตรงก่อนบันทึก
- ผู้ใช้เป็นผู้ระบุเลขครุภัณฑ์ทุกครั้ง ระบบตรวจสอบเพียงว่าเลขไม่ซ้ำ

## Settings UI

หน้าตั้งค่า “เลขครุภัณฑ์” สำหรับผู้ดูแลมีเฉพาะรายการแม่แบบ: ชื่อ, รูปแบบเลข, ค่าเริ่มต้นของ token และสถานะเปิดใช้ ไม่มีการสร้างหรือกำหนดชุดเลข

## New Item Modal

ฟอร์มเพิ่มทะเบียนใหม่มีตัวเลือกสั้น ๆ:

1. กรอกเลขครุภัณฑ์เอง
2. ใช้แม่แบบ

เมื่อใช้แม่แบบ ระบบเติม Preview ลงในช่องเลขครุภัณฑ์ ผู้ใช้คลิกและแก้ไขเลขนั้นได้โดยตรงก่อนบันทึก ไม่มีการจองหรือเพิ่มเลขให้อัตโนมัติ

## Data and Integrity

- มี unique index สำหรับเลขครุภัณฑ์ที่ไม่เป็นค่าว่าง
- CSV import ยังคงระบุแหล่งที่มาว่า import และไม่เปลี่ยนเลขอัตโนมัติ

## Verification

- เลือกแม่แบบและตรวจว่า Preview ถูกเติมลงในช่องเลข
- แก้ไข Preview ก่อนบันทึกและตรวจว่าเลขที่แก้ถูกบันทึกจริง
- ตรวจการแจ้งข้อผิดพลาดเมื่อระบุเลขซ้ำ
