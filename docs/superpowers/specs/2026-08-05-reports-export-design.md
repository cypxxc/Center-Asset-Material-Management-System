# Reports & Export System Design Specification

> **Date:** 2026-08-05  
> **Status:** Approved  
> **Target Module:** `features/reports/` & `app/(dashboard)/reports/`

---

## 1. Overview & Goal

Implement a comprehensive **Reports & Export System (Phase 6)** for the Center Asset & Material Management System (CAMMS).

The system allows staff and administrators to:
- Filter asset and material inventory across search query (`q`), item type (`type`), category (`category_id`), status (`status`), and location (`location_id`).
- Export the **full matching dataset** (up to 5,000 items) to an Excel spreadsheet (`.xlsx`) using ExcelJS with auto-formatted columns, currency styles, and summary totals.
- Generate an official PDF report document (`.pdf`) using client-side PDF export with official Thai letterhead styling, filter parameters, item data tables, and signature blocks.
- Record every export operation in the `audit_logs` table for compliance and security auditing.
- View the reports dashboard rendered with 100% Dark Mode semantic tokens (`bg-card`, `border-border`, `text-card-foreground`, `text-muted-foreground`, `bg-muted`).

---

## 2. Component & Data Architecture

### 2.1 Backend Queries & Server Actions

- **`getExportReportItems(params: ItemListSearchParams)`** (`features/reports/queries.ts`):
  - Fetches up to 5,000 items matching active filters (`q`, `type`, `status`, `category_id`, `location_id`).
  - Returns `ReportItemRow[]` along with aggregate `totalQuantity` and `totalValue`.

- **`recordReportExportAudit(format: 'excel' | 'pdf', filterSummary: string)`** (`features/reports/actions.ts`):
  - 'use server' action that creates an entry in `audit_logs` table recording `action: 'EXPORT_REPORT'`.

### 2.2 UI Component & Generators

- **`features/reports/components/reports-list.tsx`**:
  - Main client container.
  - Controls filter state for `q`, `type`, `status`, `category_id`, and `location_id`.
  - Buttons for **Export Excel (.xlsx)**, **Export PDF (.pdf)**, and **Print Report**.
  - Styled with semantic CSS tokens for full Dark Mode support.

- **Excel Generator (`exportToExcel`)**:
  - Dynamically imports `exceljs`.
  - Columns: Item Name, Type, Category, Quantity, Unit Price, Unit, Asset No, Serial No, Brand, Model, Location, Responsible Person, Status.
  - Headers styled with `fgColor: FFE2E8F0`, bold text.
  - Formats unit price as currency (`#,##0.00 ฿`).
  - Appends summary row for Total Quantity and Total Value.

- **PDF Generator (`exportToPdf` / Printable Document)**:
  - Dynamically generates downloadable PDF document using `jspdf` and `jspdf-autotable`.
  - Header: "รายงานทะเบียนทรัพย์สินและวัสดุสำนักงาน (CAMMS)".
  - Metadata block: Export date, generated by user, active filter criteria summary.
  - Table: No, Item Name, Type, Category, Quantity, Unit Price, Total Price, Location, Status.
  - Footer: Document summary totals and official approval signature lines.

## 3. UI / UX Design & Accessibility

- **Filter Bar Container:** `rounded-xl border border-border bg-card p-4 shadow-2xs grid grid-cols-1 gap-3 sm:grid-cols-2 md:grid-cols-5`
- **Filter Select Controls:** `h-9 rounded-lg border border-input bg-card px-3 text-xs font-semibold text-card-foreground focus:border-primary focus:outline-none focus:ring-1 focus:ring-primary cursor-pointer shadow-2xs`
- **Action Buttons:**
  - Excel Export: `bg-emerald-700 hover:bg-emerald-800 text-white` with `<Download className="h-4 w-4" />`
  - PDF Export: `bg-rose-700 hover:bg-rose-800 text-white` with `<FileText className="h-4 w-4" />`
  - Print: `border-border bg-card hover:bg-muted text-card-foreground` with `<Printer className="h-4 w-4" />`
- **Data Table:** Uses `bg-muted/20`, `border-border`, `text-card-foreground`, and minimum font size `text-xs` (12px).
