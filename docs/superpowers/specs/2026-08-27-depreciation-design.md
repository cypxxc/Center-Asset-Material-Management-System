# Straight-Line Depreciation Design

## Goal

เพิ่มการคิดค่าเสื่อมราคาสำหรับรายการประเภทครุภัณฑ์ ด้วยวิธีเส้นตรง โดยผู้ใช้กรอกข้อมูลที่จำเป็นเองในแต่ละรายการ และใช้มูลค่าคงเหลือ 1 บาทตามแนวทางที่ผู้ใช้กำหนด

## Scope

- ใช้ได้เฉพาะรายการที่มีประเภทเป็น `asset` (ครุภัณฑ์)
- ข้อมูลค่าเสื่อมเป็นข้อมูลทางเลือก: รายการเดิมและรายการที่ไม่เลือกคิดค่าเสื่อมยังใช้งานได้ตามปกติ
- รองรับการแก้ไขข้อมูลค่าเสื่อมในภายหลัง พร้อมคำนวณผลลัพธ์ใหม่ทันที
- ไม่สร้างค่าเริ่มต้นจากหมวดหมู่หรือแม่แบบ เพื่อให้ผู้ใช้กรอกข้อมูลเองต่อรายการ

## Data Model

เก็บข้อมูลกับรายการครุภัณฑ์โดยตรง:

- สถานะเปิดใช้การคิดค่าเสื่อม
- มูลค่าพร้อมใช้งาน (บาท)
- อายุการใช้งาน (จำนวนปีเต็มที่มากกว่า 0)
- รูปแบบวันเริ่มคิด: วันที่ได้มา, วันที่พร้อมใช้งาน, หรือกำหนดวันเอง
- วันเริ่มคิดที่สอดคล้องกับรูปแบบที่เลือก
- วิธีคิด `straight_line`
- มูลค่าคงเหลือ 1.00 บาท

การตรวจสอบต้องไม่ยอมให้มูลค่าพร้อมใช้งานต่ำกว่าหรือเท่ากับ 1 บาท, อายุใช้งานไม่ถูกต้อง, หรือวันที่เริ่มคิดหายไปเมื่อเปิดใช้การคิดค่าเสื่อม

## Calculation

ระบบคำนวณเป็นเงินบาทและปัดทศนิยมสองตำแหน่งเพื่อแสดงผล:

```
ค่าเสื่อมราคาต่อปี = (มูลค่าพร้อมใช้งาน - 1.00) / อายุการใช้งาน
```

- ค่าเสื่อมสะสมคำนวณตามสัดส่วนเวลาตั้งแต่วันเริ่มคิดถึงวันปัจจุบัน โดยไม่เกินมูลค่าที่คิดค่าเสื่อมได้
- มูลค่าสุทธิตามบัญชี = มูลค่าพร้อมใช้งาน - ค่าเสื่อมสะสม
- มูลค่าสุทธิตามบัญชีต้องไม่ต่ำกว่า 1.00 บาท แม้ผ่านอายุการใช้งานครบแล้ว
- วันที่เริ่มคิดในอนาคตมีค่าเสื่อมสะสมเป็น 0 บาท

การคำนวณเป็นผลลัพธ์ ณ วันที่เรียกดู ไม่บันทึกยอดสะสมซ้ำลงฐานข้อมูล จึงคงความถูกต้องเมื่อเวลาผ่านไปหรือเมื่อผู้ใช้แก้ไขข้อมูลตั้งต้น

## User Experience

### Form

ในฟอร์มเพิ่มและแก้ไขครุภัณฑ์ เพิ่มส่วน “การคิดค่าเสื่อมราคา” ที่ยุบได้:

1. สวิตช์เปิดใช้การคิดค่าเสื่อม
2. เมื่อเปิดแล้ว แสดงช่องกรอกมูลค่าพร้อมใช้งานและอายุใช้งาน
3. เลือกรูปแบบวันเริ่มคิด แล้วแสดงช่องวันที่ที่มีป้ายกำกับตามตัวเลือก
4. แสดง Preview ของค่าเสื่อมต่อปีและมูลค่าคงเหลือ 1 บาทก่อนบันทึก

วัสดุสิ้นเปลืองจะไม่แสดงส่วนนี้ และการเปลี่ยนประเภทรายการจากครุภัณฑ์เป็นวัสดุจะปิดการใช้ข้อมูลค่าเสื่อมโดยไม่ลบข้อมูลเดิมโดยอัตโนมัติ

### Item Detail

หน้ารายละเอียดครุภัณฑ์ที่เปิดใช้จะแสดงบัตร “การคิดค่าเสื่อมราคา” ประกอบด้วย วิธีคิด, มูลค่าพร้อมใช้งาน, มูลค่าคงเหลือ, อายุใช้งาน, วันเริ่มคิด, ค่าเสื่อมต่อปี, ค่าเสื่อมสะสม ณ วันนี้ และมูลค่าสุทธิ ณ วันนี้

### Report

เพิ่มรายงานสรุปค่าเสื่อมสำหรับครุภัณฑ์ที่เปิดใช้การคิดค่าเสื่อมเท่านั้น โดยมีตารางรายการและยอดรวมของมูลค่าพร้อมใช้งาน, ค่าเสื่อมสะสม, และมูลค่าสุทธิ ผู้ใช้สามารถใช้การส่งออกตามกลไกรายงานที่มีอยู่ได้

## Authorization and Realtime

- การเพิ่มหรือแก้ไขค่าเสื่อมใช้สิทธิ์เดียวกับการเพิ่มหรือแก้ไขรายการครุภัณฑ์ในปัจจุบัน
- การอ่านใช้สิทธิ์เดียวกับการอ่านรายการ
- การเปลี่ยนแปลงข้อมูลจะได้รับการรีเฟรชแบบ realtime ในหน้ารายละเอียดและรายงาน ผ่านการ subscribe ตาราง `items` ที่มีอยู่

## Testing and Verification

- Unit test การตรวจสอบข้อมูล: เปิดใช้แล้วต้องมีข้อมูลครบ, มูลค่ามากกว่า 1, อายุใช้งานมากกว่า 0 และวันที่ถูกต้อง
- Unit test สูตร: ค่าเสื่อมต่อปี, การปัดเศษ, วันเริ่มในอนาคต และเพดานมูลค่าคงเหลือ 1 บาท
- Integration test การสร้างและแก้ไขครุภัณฑ์พร้อมข้อมูลค่าเสื่อม
- ตรวจรายการที่ไม่เปิดใช้และรายการประเภทวัสดุไม่ปรากฏในรายงานค่าเสื่อม
- ตรวจ typecheck, lint และชุดทดสอบที่เกี่ยวข้อง
